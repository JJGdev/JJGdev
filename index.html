Sobre mí

👋 ¡Hola! Soy Juan

Me llamo Juan García. Trabajo a jornada completa y, en el tiempo que queda, estudio desarrollo web. Este portfolio es mi primer proyecto real: lo estoy construyendo mientras aprendo, y cada commit es una pequeña lección.

Mi forma de aprender es poco tradicional: colaboro con IA para escribir código que todavía no sabría escribir solo, y después lo destripo hasta entender cómo funciona. Algunos lo llaman vibe coding; para mí es la forma más honesta de avanzar rápido sin saltarme la parte de comprender.

Documento todo el proceso en el blog — los errores también, porque es donde más se aprende. Si buscas a alguien con ganas, constancia y cero miedo a equivocarse, hablamos.

Proyectos

Web · Portfolio · Primer proyecto

JJGdev Portfolio v1.0

Mi primer proyecto real como desarrollador web. Un portfolio personal construido desde cero con HTML, CSS y JavaScript puro, sin frameworks ni plantillas. El proceso de hacerlo fue también mi primera toma de contacto real con el desarrollo web asistido por IA: aprender qué es un repositorio, cómo funciona el despliegue con Netlify, y cómo iterar sobre un diseño real con un objetivo concreto. Este sitio no es solo un portfolio, es el registro en tiempo real de cómo estoy aprendiendo.

Web app · Fotos de boda · En desarrollo

WedToShare

Una plataforma pensada para que los invitados de una boda puedan subir y compartir sus fotos del evento en un mismo sitio, sin depender de grupos de WhatsApp ni de álbumes dispersos. Es mi proyecto más ambicioso hasta ahora: el primero en el que trabajo con backend real y base de datos, no solo frontend. Todavía no está lista ni es pública, así que de momento prefiero no adelantar más detalles, pero es donde estoy invirtiendo la mayor parte de mi aprendizaje ahora mismo.
